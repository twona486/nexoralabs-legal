Project RECLAIM 데이터 삭제 안내

시행일 2026년 11월 24일

넥소라랩스(Nexora Labs)가 운영하는 Android 게임 Project RECLAIM(com.nexoralabs.reclaim)의 익명 계정과 데이터를 삭제할 수 있습니다.

게임에서 삭제

  1. 설정 → 계정 및 데이터 삭제 → 계속 → 영구 삭제를 선택합니다.
  2. 삭제 완료 안내가 표시될 때까지 기다립니다. 네트워크 오류가 발생하면 인터넷 연결을 확인한 뒤 앱에서 다시 시도하세요.
  3. 만 14세 이상에서 이 절차를 이용하면 Firebase에 저장된 게임 진행과 익명 계정, 이 기기의 게임 저장 파일이 삭제됩니다. 만 14세 미만에서는 기기의 게임 저장 파일을 삭제합니다. 삭제한 게임 진행은 복구할 수 없습니다.

만 14세 미만으로 설정하기 전에 전송된 클라우드 데이터는 아래 이메일로 삭제를 요청할 수 있습니다. 기기 저장을 선택해도 이미 전송된 데이터는 각 서비스의 보유 기준을 따릅니다.

앱이 없어도 이메일로 삭제 요청

cs@nexoralabs.io에 삭제 요청 보내기

메일 제목에 Project RECLAIM 데이터 삭제 요청을 적어 주세요. 익명 계정 ID를 알고 있다면 포함해 주세요. 만 14세 이상에서 로그인한 경우 앱의 삭제 안내 화면에서 삭제 요청용 계정 ID 복사를 이용할 수 있습니다. ID를 모르면 사용 기기와 대략적인 첫 이용일 또는 마지막 이용일을 알려 주세요. 익명 계정은 이메일과 연결되지 않으므로 계정 확인에 필요한 추가 정보를 요청할 수 있습니다. 비밀번호, 인증 토큰, 카드 정보는 보내지 마세요.

계정을 확인한 뒤 클라우드 저장 데이터와 익명 계정을 삭제하고 처리 결과와 보존 예외를 이메일로 안내합니다. 기기에 남은 데이터는 앱 내 삭제 기능 또는 Android의 앱 데이터 삭제로 정리할 수 있습니다.

별도로 보관되는 데이터

법령상 보존 의무가 적용되면 계약·청약철회 및 결제·공급 기록은 5년, 소비자 불만·분쟁 처리 기록은 3년, 표시·광고 기록은 6개월간 별도로 보관합니다. Google Play의 구매 내역은 Google에서 관리합니다. 만 14세 이상에서 게임의 계정 삭제 기능을 이용하면 앱의 분석 식별자도 초기화됩니다. 이미 Google로 전송된 분석·광고 데이터는 서비스별 보관 기준을 따릅니다. 해당 데이터에 관한 열람·삭제 요청은 위 이메일로 보내 주세요. 자세한 기준은 개인정보처리방침에 있습니다.
